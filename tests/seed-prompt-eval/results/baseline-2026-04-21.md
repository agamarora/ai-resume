## Judge notes

- **Llama 3.3 70B judge**: more discerning, gives partial credit, stable scoring — but collides with 70B-as-agent on TPM quota (per-minute cap, not daily).
- **Llama 3.1 8B judge**: cheap, fast, no TPM conflict with agent tests — but noisy on ambiguous prompts (v0's vague language reads differently to it each run). Good at flagging clear wins (v1 stays at 97.5%).

For future iteration: prefer 70B judge when TPM budget allows. 8B judge is fine as a
cheap regression check — if v1 ever drops below 95% on 8B, it has a real problem.

## Headline findings

- Dumb-model floor (Llama 8B as agent) scores v1 at 97.5% on every run. Weak agents execute correctly.
